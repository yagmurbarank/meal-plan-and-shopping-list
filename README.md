# 👨‍🍳 Meal Planner & Grocery Aggregator

Modern, tema destekli ve esnek gün sayısı kısıtlaması olmayan **Haftalık Yemek & Alışveriş Listesi Planlayıcısı**. Türk mutfağından lezzetlerle menü oluşturmayı ve malzeme toplamayı pratikleştirir.

---

## 🚀 Özellikler

* **♾️ Sonsuz Gün Planlama:** Sabit bir gün sınırı olmaksızın istediğiniz kadar günlük menü hazırlayın.
* **👥 Dinamik Porsiyonlama:** Kişi sayısı seçimine göre malzeme miktarları otomatik çarpanla güncellenir.
* **🌾 🌱 Beslenme Filtreleri:** Glutensiz ve Vegan yemek süzgeçleri ve görsel rozet (emoji) gösterimleri.
* **🌗 Çift Tema Desteği:**
  * **Aydınlık Tema:** Ferah Pastel Mavi & Yeşil tonları.
  * **Karanlık Tema:** Şık Bordo & Lacivert renk paleti.
* **🛒 Akıllı Malzeme Toplama:** Seçilen tüm günlerdeki tekrarlanan malzemeleri miktar ve birim bazında otomatik birleştirir.
* **🖨️ Yazdırma / PDF Optimizasyonu:** Özelleştirilmiş `@media print` CSS kuralları ile temiz baskı çıktısı.
* **📋 Kopyalama:** Tek tıkla Whatsapp/Notlar uygulamasına yapıştırılabilir biçimlendirilmiş liste kopyalama.

---

## 🛠️ Teknolojiler

* **Frontend:** React 18 / 19
* **Build Tool:** Vite
* **Styling:** Tailwind CSS v4
* **Icons:** Emoji-based native badge System
